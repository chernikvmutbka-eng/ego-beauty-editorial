# EGO Beauty — editorial duplicate

Отдельный дубль магазина EGO Beauty в редакционном минималистичном стиле. Исходный сайт и его публикация этим проектом не изменяются.

## Что изменено

- Новая главная: полноэкранный слайдер, крупная типографика, категории, история бренда и тематические подборки.
- Расширенная структура каталога и подкатегорий из ТЗ.
- Отдельные страницы «О бренде» и «Информация / FAQ».
- Сравнение покупки на сайте, Wildberries и Ozon в карточках и на странице товара.
- Цена маркетплейса показывается только при наличии подтверждённого значения; иначе предлагается открыть поиск и проверить цену.
- Колесо фортуны принимает Telegram-ник, даёт одну попытку и назначает суперприз каждому 300-му участнику.
- Сохранены корзина, избранное, checkout, D1, сотрудничество, кабинет и admin из функциональной основы.

## Запуск

Требуется Node.js 22.13+.

```bash
npm ci
npm run dev
```

Проверки:

```bash
npm run typecheck
npm run lint
npm test
```

## Данные и интеграции

Снимок цен датирован 04.08.2026. Перед реальными продажами необходимо подключить источник актуальных цен и остатков для сайта, Wildberries и Ozon, подтвердить юридические тексты, подключить оплату и доставку.

Для автоматической проверки подписки на Telegram задайте `TELEGRAM_VERIFY_URL`. Адаптер должен принимать POST `{ "username": "..." }` и возвращать `{ "subscribed": true | false }`.
